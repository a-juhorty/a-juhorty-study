일제의 식민지 통치

무단 통치, 문화 통치, 민족 말살 통치

조선 총독
  • 일본 왕이 임명, 육·해군 대장 출신
  • 행정·사법·입법권 + 군 통수권
통치 방식 3단계
  1. 11910년대 무단 통치
  2. 21920년대 문화 통치 (민족 분열)
  3. 31930~45 민족 말살 통치
1910년대 무단 통치
  • 헌병 경찰이 치안·행정·사법 담당, 즉결 처분권
  • 조선 태형령: 조선인에게만 적용 → 민족 차별·폭압
  • 언론·집회·결사 금지, 관리·교원 제복·칼 착용
  • 1911 조선 교육령: 낮은 수준의 보통·실업 교육, 일본어
1920년대 문화 통치
  • 배경: 3·1 운동, 국제 여론 악화
  • 표면: 문관 총독 가능, 보통 경찰, 동아·조선일보 허용
  • 실체: 문관 총독 임명된 적 없음, 경찰 증가, 치안 유지법(1925), 검열 강화
  • 사이토 마코토: 친일파 양성 → 민족 분열
민족 말살 통치(1931~45)
  • 배경: 대공황 → 침략 전쟁(만주사변·중일·태평양)
  • 황국 신민화: 내선일체·일선 동조론
  • 황국 신민 서사 · 창씨개명(1940) · 신사 참배 · 궁성 요배
  • 조선어·조선사 교육 금지, 국민학교, 신문 폐간(1940)
조선 교육령 변화
  1. 11911 보통·실업 교육
  2. 21938 조선어 선택 과목
  3. 31941 국민학교
  4. 41943 조선어·조선사 폐지
국가 총동원법(1938) 이후 수탈
  • 인적: 지원병(1938) · 학도 지원병(1943) · 징병(1944) · 국민 징용령(1939) · 여자 정신 근로령(1944) · 위안부
  • 물적: 미곡 공출 · 금속류 공출 · 식량 배급제
  • 통제: 애국반
치안 유지법(1925)
  • 국체(천황제)·사유 재산 제도 부정 결사 처벌 → 사회주의·독립 운동 탄압
일본군 '위안부' 문제
  • 강제 동원된 전쟁 범죄·인권 침해
  • 해결: 일본의 사죄와 배상, 기억하기

일제의 식민지 경제 정책

토지 조사, 회사령, 산미 증식, 병참 기지화

토지 조사 사업(1910~)
  • 명분: 근대적 토지 소유권 확립, 공평한 지세
  • 목적: 지세 수입 확보, 일본인 토지 차지
  • 방식: 신고주의 → 미신고지·국유지가 총독부 귀속 → 동양 척식 주식회사·일본인에게
  • 결과: 경작권 부정 → 소작농 전락·화전민·만주 이주, 지주제 강화
동양 척식 주식회사
  • 1908 설립 국책 회사
  • 귀속 토지를 싸게 받아 최대 지주 → 농민 소작 수탈
회사령(1910) → 폐지(1920)
  • 1910: 허가제 → 한국인 기업 성장 억제
  • 1920: 신고제로 폐지 → 1차 대전 호황의 일본 자본 진출 도움
1910년대 산업 침탈
  • 삼림령·광업령·어업령으로 산림·광산·어장 장악
  • 철도·금융 장악, 담배·인삼 등 전매
산미 증식 계획(1920~)
  • 목적: 일본의 식량(쌀) 부족 해결
  • 결과: 증산량 < 반출량 → 조선인 쌀 소비 감소, 만주 잡곡
  • 수리조합비 농민 전가 → 농민 몰락, 단작형 농업, 지주제 강화
1930년대 병참 기지화
  • 대륙 침략 물자·인력 공급 → 북부 발전소·중화학 공업 육성
  • 결과: 남부 경공업 / 북부 중화학 → 공업 구조 불균형
  • 남면 북양: 남부 면화, 북부 양 사육
농촌 진흥 운동·조선 농지령
  • 농촌 진흥 운동(1932) · 조선 농지령(1934)
  • 표면: 농촌 안정, 지주·소작인 갈등 완화
  • 실제: 농민 운동 무마·농촌 통제 강화
  • 한계: 농민 책임만 강조, 지주 옹호 → 근본 문제 미해결
전시 공출·배급
  • 쌀·놋그릇·금속 공출, 식량 배급제 → 농민 굶주림, 애국반 통제

  • 국외: 신한 청년당(김규식 → 파리 강화 회의) · 대한 독립 선언(1918) · 2·8 독립 선언(1919)
  • 국내: 고종 서거·독살설 (1919.1)

  4. 4일제 탄압 (제암리 사건)
  • 특징: 전 계층 참여 · 비폭력으로 시작, 농촌은 폭력으로 변하기도

  • 임시 정부 수립 토대
  • 거족적 항일 운동 · 노동자·농민·여성 주체 확대
  • 5·4 운동 등 아시아 민족 운동에 영향
대한독립선언서 vs 2·8 독립 선언서
  • 대한독립선언서(1918): 만주 지린, 39인, 독립 전쟁(무장 투쟁)
